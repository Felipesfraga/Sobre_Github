# Secão 1

## O início:
Para criar um repositoriuo no GitHub eu vou em todos os Repositorios e vai no botão (NEW REPOSITORY) e depois para contruilo coloque um Tilulo do Repositorio e a descrição dele, vc também pode colocar publico ou privado para vc e também adicionar (README.md) que serve para descrição longas.

## A conxão:
Para vincular uma pasta local no meu computador e colocar na nuvem vc tem que ir no Repositorio criado, clicar em (+) e clicar em: "Carregar arquivos" e depois vá em: "Escolha seus arquivos" , ai vc vai procurar a pasta local do seu arquivo dentro do PC e selecionar eles e depois para salvar aperte em "Confirmar alrterações" e assim vai ficar salvo seu repositorio remoto criado na nuvem do GitHub.

## Primeiro Envio:
Primeiro vc tem que criar um repositorio no GitHub e depois pegue o arquivo local e adicione no repositório do GitHub e depois salve ele.


# Sessão 2

## Propósito:
O **README.md** serve para uma descrição detalhada longa do seu projeto, descrevendo o que é o seu Repositório, como deve ser utilizado, e até como baixalo e etc... O README.md é para o público-alvo que for acessar seu arquivo e queira entender como funciona o seu repositório, buscando compreenção e a utilidade para tal e atambém para o usuario poder utilizalo.

## Dados Fundamentais:
**As informações essenciais de um README é** 

**1-Titulo** que deve ser posto, pois com o Titulo a gente vai entender qual é o projeto.

**2-Tecnologias Utilizadas** serve para o publico-alvo saber qual linguagem e versão foi utilizada no projeto, assim eles podendo fazer também.

**3- Como instalar/rodar,** é uma descrição importante pois as pessoas que quiserem utilizalo podem seguir o passo a passo para conseguir.

**4-Desenvolvimento** é bom pois vai explicar como foi montado para poder rodar e entender os modos para isso.

**5-Descrição** é um aprofundamento do porque desse projeto explicando detalhadamente as etapas dele.

## O poder do Markdown:
**Markdown** é uma linguagem de marcação de textos bem rapida e dinamica que utiliza os botões do teclado sem precisar de menus complexos e de editores.

## GitHub Online:
Para atualizar o o arquivo pelo navegaor vc tem que ir no arquivo que for editar e apertar ("Edite este arquivo") e depois só colocar o arquivo editado nesse repositorio e depois (confirmar alterações)

Quando for atualizar é o momento de otimizar o esse côdigo ou quando tem erro de digitação do côdigo

As limitações são, vc não consegue rodar o código para testar se quebrou a aplicação antes de enviar e tammbém se duas pessoas forém salvar o repositório ao mesmo tempo ele entra em conflito e buga o repositório fazendo que não rode nem o repositório.
